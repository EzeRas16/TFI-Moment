# TFI-Moment
App web interactiva para casamientos y eventos. Gestión de retos fotográficos mediante QR y encuestas en vivo. Frontend en Angular 22.
App Interactiva para Eventos 💍📸
Aplicación web desarrollada como Trabajo Práctico Final / Trabajo Final Integrador (TFI) para la Tecnicatura Universitaria en Programación de la UTN - Facultad Regional Mar del Plata.

La plataforma permite a los organizadores (novios) gestionar su casamiento, crear mesas y generar códigos QR únicos. Los invitados acceden escaneando el QR para interactuar a través de retos fotográficos y encuestas en tiempo real, generando un álbum virtual colaborativo.

 Stack Tecnológico (Etapa 1)
Frontend: Angular 22 (Standalone Components, Control Flow)

Estilos: SCSS

Backend Simulado: JSON Server (Mock API RESTful)

Gestión de Imágenes: Cloudinary (Unsigned Uploads)

Proyección (Etapa 2): Preparado para migración a API REST en Java Spring Boot con MySQL.

 Funcionalidades Principales
Gestión de Accesos: Autoregistro de invitados mediante escaneo de código QR en la mesa.

Retos Fotográficos: Asignación de misiones (ej. "Foto con el cotillón") por mesa o evento general.

Galería en Vivo: Visualización en tiempo real de las fotos subidas, con sistema de "Me gusta" y filtros por mesa/reto.

Encuestas en Vivo: Votaciones interactivas (ej. "Elección de la próxima canción") con resultados dinámicos.

Álbum Virtual: Herramienta de moderación para que los organizadores filtren y exporten sus fotos favoritas.
